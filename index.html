First Victor List

ถ้าคุณได้ผ่าน obby ที่ยังไม่มีใครผ่าน หรือ First Victor ส่งใน Discord ลงใน Youtube, medal และอื่นที่ลงคลิปยาวได้ ไม่เอา Tiktok (ถ้าไม่มีถือว่าเป็นโมฆะ)

Tower List : Terrifying + ขึ้นไป
Obby List : Tier 14 + ขึ้นไป
Pace Based List : 7.00 + ขึ้นไป

Top Rank

  • กรณี 1. มีคลิปผ่าน Insane (8.00) Towers อย่างน้อย 3 Tower หรือถ้ามีมากกว่า Insane (8.00) คือ Extreme (9.00) 1 Tower ขึ้นไปสามารถลงได้
  • กรณี 2. มีคลิปผ่าน Tier 13 อย่างน้อย 3 Obby หรือถ้ามีมากกว่า Tier 13+ คือ Tier 14 1 Obby ขึ้นไปก็สามารถลงได้เหมือนกัน
  • กรณี 3. ถ้าเล่น FE2 หรือแนว Paced Based มีคลิปผ่านระดับ Extreme หรือ ETOH difficulty Insane ขึ้นไป 3 Obby ก็สามารถลงได้เหมือนกัน ทั้งหมดกรณีนี้ต้องมี raw footage หรือวิดิโอที่ไม่มีตัดต่อ
  • กรณี 4. มี Progress Tower/Obby ประมาณ 80% ก็คือถึง floor 8-9 ขึ้นและ ต้องเป็นระดับไม่ต่ำกว่า Mid Horrific (12.50) ก็เข้าได้เหมือนกัน ส่งวิดิโอที่ถ่ายตอนเล่น fail และส่ง Message Progress ในดิส

ข้อห้าม และ ข้อกำหนด

  • ไม่อนุญาตให้เปลี่ยน account roblox อื่นเล่น เพื่อป้องกันการ แอบเนียน copy video คนอื่น ถ้าจะเปลี่ยนโปรดแจ้ง staff หรือ listmod
  • เมื้อส่งมาแล้วเราจะตรวจสอบก่อนเข้า list เพื่อให้ชัวว่าคุณจะไม่โกหกหรือโกง ถ้าหากคุณ โกหกหรือโกง การผ่านของคุณถือว่าเป็นโมฆะทันที พร้อม ListBanned
  • นับจาก Popular Game เช่น EToH, EToH:Tea, CSCD and AToS รวมถึงแมพ fangame อื่นๆที่มีในระบบ Towerstats และ แมพต่างๆที่มี SCLP ไม่นับ Joke Tower หรือ จากเกม Tower Creator และ Obby Creator
  • ระบุชื่อ Place Location หรือ Tower ทุกคลิป

วิธีคำนวณ Point

เราจะเอา Hardest 1-5 ของคุณมา คูณและบวกรวม โดยจะมี Point ที่กำหนดไว้ใน Sheet แล้ว

(Hardest 1 * 1) + (Hardest 2 * 0.66) + (Hardest 3 * 0.45) + (Hardest 4 * 0.3) + (Hardest 5 * 0.2)
